A one-line joke about office life for the
[u-myronera-one-line-one-laugh-the-office-joke-open-fe8204d4](https://make.fun/bounty/u-myronera-one-line-one-laugh-the-office-joke-open-fe8204d4)
bounty on [make.fun](https://make.fun/r/0ene8b3q) — one line, at most 200
characters, with the punchline landing in the last few words.

## The line

> I told my boss I work best under pressure, so he moved all my deadlines to yesterday.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, within the 200 character limit. It
also prints the same text to stdout.

## Run it

```sh
node main.ts
```
